# 铸钟内壁车削调音方案系统

供铸钟修复师制定内壁车削调音方案的本机 Web 应用。

## 运行

```bash
pip install -r requirements.txt
python3 app.py        # 打开 http://127.0.0.1:5000
```

首次使用点击「载入演示钟」即可看到完整流程。

## 功能

1. **钟体录入**：母线截面点列（z 自唇口向上 / 内半径 / 壁厚）、材料密度、
   A4 基准、目标音高（音名自动生成 hum/prime/tierce/quint/nominal 五分音目标，
   比例 0.5 / 1 / 1.2 / 1.5 / 2.0，可手改频率与容差）。
2. **测量导入**：每轮敲击测得的频率与置信度按轮次标签批量导入。
3. **壳体近似模型**：母线离散为 24 个等弧长环带；按各分音典型子午向振型
   （节线圆位置）与环向波数 n=2,2,3,3,4 计算弯曲能/膜能/动能分布，
   得灵敏度矩阵 S（每 mm 去料的相对频变）。既有切削记录按置信度加权
   最小二乘拟合每分音标定系数 α，并给出预测可信度。
4. **SVG 圈选**：在截面上点击/Shift 连选环带，滑块或滚轮调整去料深度，
   即时预览五个分音频率与音分偏差；灵敏度热图显示耦合关系。
5. **自动检查**：壁厚不足（硬错误）、振型次序交叉、耦合越界、
   以及基于有界最小二乘的「仅靠去料是否可达」分析。
6. **轮次拆分**：方案按单刀深度与车床步进拆成多轮车削 + 复测节点；
   录入复测值后自动生成切削记录、更新标定 α 与后续预测。
7. **版本比较与导出**：任意两版本并排比较；导出标注轴向位置、切削深度、
   禁止区与复测频率的 SVG 工艺单及 JSON。

## 说明

模型为工程近似（等效壳体能量的线性化灵敏度），用于方案规划与轮次间预测更新；
α 标定会随切削记录积累逐步贴合具体钟体。预测不可达的目标需采用其他工艺
（如改变悬挂/结构或接受折中音高）。
